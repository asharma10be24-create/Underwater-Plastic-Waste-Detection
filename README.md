
# Underwater Plastic Waste Detection and Segmentation

## Project Overview
An image processing and deep learning project that detects and segments underwater marine waste using YOLO11 Instance Segmentation.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- PyTorch
- YOLO11n-seg
- Google Colab

## Image Processing Techniques
- CLAHE Contrast Enhancement
- Gamma Correction
- Median Filtering
- Gaussian Filtering

## Dataset
TrashCan 1.0 Dataset:
https://conservancy.umn.edu/handle/11299/214865

## Model
YOLO11n Instance Segmentation

## Training
- Epochs: 50
- GPU: NVIDIA Tesla T4
- Training Images: 6065
- Validation Images: 1147

## Results
- Segmentation mAP50: 58.41%
- Segmentation mAP50-95: 36.34%
- Mask Precision: 77.1%
- Mask Recall: 53.3%
